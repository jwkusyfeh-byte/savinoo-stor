# SAVINOO STORE — سافينوو ستور

متجر اشتراكات رقمي مع صفحة عامة ولوحة إدارة، بدون منتجات أو أسعار افتراضية.

## التشغيل والنشر

1. أنشئ مشروعاً في [Supabase](https://supabase.com).
2. افتح **SQL Editor** وشغّل `supabase/setup.sql`.
3. من **Authentication > Users** أنشئ مستخدم الأدمن ببريدك وكلمة مرور قوية.
4. انسخ UUID الخاص بالمستخدم، وشغّل هذا الأمر في SQL Editor بعد استبدال القيمة:
   `insert into public.admins(user_id) values ('UUID-OF-YOUR-ADMIN');`
5. انسخ `.env.example` إلى `.env.local` وأضف `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` من Supabase > Project Settings > API.
6. شغّل `npm install` ثم `npm run dev`.
7. افتح `http://localhost:3000` للمتجر و`http://localhost:3000/admin` للأدمن.
8. للنشر، ارفع المشروع إلى GitHub ثم استورده في [Vercel](https://vercel.com) وأضف متغيرات البيئة نفسها. تحصل على رابط عام ومسار `/admin`.

## مهم

- لا تستخدم مفتاح `service_role` في المتصفح أو متغير `NEXT_PUBLIC_`.
- رابط `/admin` ليس سرياً بحد ذاته؛ الأمان عبر تسجيل الدخول وسياسات قاعدة البيانات.
- ابدأ بإضافة منتجاتك وصورك وأسعارك بنفسك من لوحة الإدارة.
- رقم واتساب يُدخل بصيغة دولية من دون علامة + (مثال: 9647...).
- هذا إصدار أولي عملي: إدارة المنتجات والصور والتصميم الأساسي وواتساب. لا يتضمن بعد محرر صفحات حرّاً، إحصائيات، أو مؤثرات متقدمة قابلة للتخصيص.
- إن لم تضبط Supabase فلن تعمل عمليات الحفظ والرفع؛ يجب إكمال خطوات الربط أولاً.
